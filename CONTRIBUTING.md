# 🛡️ VyaadhiShield AI — Disease Outbreak Early Warning System

## Contributing

Thank you for considering contributing to VyaadhiShield! This project was built for Smart India Hackathon (SIH) and welcomes contributions.

### How to Contribute

1. **Fork** the repository
2. **Clone** your fork: `git clone https://github.com/YOUR-USERNAME/AI-DISEASE-DETECTION.git`
3. **Create a branch**: `git checkout -b feature/amazing-feature`
4. **Make changes** and test them
5. **Commit**: `git commit -m 'feat: Add amazing feature'`
6. **Push**: `git push origin feature/amazing-feature`
7. **Open a Pull Request**

### Development Setup

```bash
# Backend
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

# Frontend
cd frontend
npm install
npm run dev -- --port 3000
```

### Areas for Contribution

- 🐛 Bug fixes
- 📝 Documentation improvements
- 🌐 Additional language translations
- 📊 New visualization components
- 🤖 ML model improvements
- 🧪 Test coverage
- ♿ Accessibility improvements

### Code Style

- **Python**: PEP 8, type hints, docstrings
- **JavaScript/React**: Functional components, hooks, inline styles with CSS variables
- **Commits**: Follow conventional commits (`feat:`, `fix:`, `docs:`)
